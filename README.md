# tted (Terminal Text EDitor)

A lightweight, blazing-fast terminal text editor built in Python. 

## Features
* Fast startup (Ahead-of-Time compiled via Nuitka)
* Minimalist status bar interface
* Native terminal support

## Installation & Usage

**For Windows Users (No Python required):**
1. Go to the **Releases** section on the right side of the GitHub page.
2. Download the `tted.exe` file.
3. Open your terminal or command prompt and run the executable.

**For Developers (Run from source):**
1. Clone the repository: `git clone https://github.com/coder2837/tted.git`
2. Run the script: `python tted/tted.py`
